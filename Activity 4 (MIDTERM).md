## 🍃 01 — Introduction

> Google Sheets is a web-based spreadsheet application developed by Google. It allows users to organize, calculate, analyze, and present information using rows and columns.

| 🌱 Feature | Description |
|:--|:--|
| 🌐 Web-based | Access spreadsheets online |
| ☁️ Auto-save | Save changes to Google Drive |
| 🤝 Collaboration | Work with others in real time |
| 🧮 Calculations | Use formulas and functions |
| 📊 Data analysis | Sort, filter, and visualize information |

## 🌿 03 — Understanding the Interface

| Component | Description | Example |
|:--|:--|:--|
| Rows | Horizontal sections | 1, 2, 3 |
| Columns | Vertical sections | A, B, C |
| Cell | Intersection of a row and column | A1 |
| Cell reference | Address of a cell | B4 |
| Formula bar | Displays or edits formulas | `=SUM(B2:B10)` |
| Sheet tabs | Switch between worksheets | Sheet1 |
| Toolbar | Formatting and editing tools | Font, borders |
| Name box | Shows selected cell reference | A1 |

> **Remember:** B4 refers to Column B and Row 4.

## 🍀 05 — Sorting & Filtering

**Sorting** arranges information in a specific order:
- Alphabetically from A–Z or Z–A
- Numerically from lowest to highest
- Numerically from highest to lowest

**Filtering** displays only information that meets a condition.

*Example: Show patients aged 60 and above without deleting other records.*

## 🌷 07 — Formatting & Validation

**Conditional formatting** changes a cell's appearance when a condition is met.

Example: Temperature ≥ 38°C → highlight the cell.

**Data validation** controls the information users can enter, such as selecting a patient status from a dropdown list.

## 🧮 09 — Common Formulas & Functions

| Function | Purpose | Example |
|:--|:--|:--|
| SUM | Adds numbers | `=SUM(B2:B10)` |
| AVERAGE | Calculates the mean | `=AVERAGE(B2:B10)` |
| COUNT | Counts numeric cells | `=COUNT(B2:B10)` |
| MAX | Finds the highest value | `=MAX(B2:B10)` |
| MIN | Finds the lowest value | `=MIN(B2:B10)` |
| IF | Returns a conditional result | `=IF(B2>=75,"Passed","Failed")` |
| COUNTIF | Counts matching cells | `=COUNTIF(B2:B10,">=75")` |
| SUMIF | Adds matching values | `=SUMIF(A2:A10,"Nursing",B2:B10)` |
| ROUND | Rounds a number | `=ROUND(B2,2)` |
